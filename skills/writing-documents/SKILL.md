# writing-documents

Write the document under the following rules.

## Rules

1. Write no prose.
2. Use only bullets, tables, and code blocks.
3. Write one sentence per bullet.
4. Give every bullet a subject.
5. Fill each table cell with a word or phrase, never a sentence.
